ls -al 
    drwxr-xr-x   3 root    root    4096 Oct 15  2024 .
    drwxr-xr-x  24 root    root    4096 Nov  8  2024 ..
    drwxr-x--- 104 saharsh saharsh 4096 Aug 17 22:38 saharsh

    rwx - read, write, execute

    drwxr-x--- 104 saharsh saharsh 4096 Aug 17 22:38 saharsh
    │└──┬──┘
    │   │
    │   permissions
    └── directory

    rwx | r-x | ---
    ↓     ↓     ↓
    User  Group Others

    - user can read + write + execute
    - group can read + execute
    - other can not do anything

    one thing to remember r = 4 , w = 2 , x = 1
    .. rwx = 4 + 2 + 1 = 7
    .. r-x = 4 + 0 + 1 = 5
    .. --- = 0 + 0 + 0 = 0
    so the directoy has permissions 750



chmod - change mode / chnage permissions
    - chmod u+x file/name
    - chmod u-x file/name
    - chmod g+x file/name
    - chmod g-x file/name
    - chmod a+x file/name - all 

chown - Change Owner
    - ls -l file/path - show the details & Owner
    - sudo chown new/Owner/Name file/name
    -Ex. ls -l script.sh
    - sudo chown saharsh script.sh
    - owner chnaged

umask - default permission change
    - default permission for the file - 666
    - for the directories 777
    - if default permission is 666
    - we d umask 022
    - 066 - 022 = 044 the permission will chnage
